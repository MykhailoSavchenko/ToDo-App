# 📝 ToDo App — React Task Manager

A simple and practical ToDo application built with **React** for managing tasks in the browser.
Features include adding, completing, deleting, filtering, and persisting tasks between sessions.

## 🚀 Live Demo

👉 https://mykhailosavchenko.github.io/ToDo-App/

_(If the demo isn’t showing, ensure you’ve run the deploy script and the `homepage` field in `package.json` is correct.)_

## 🌟 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks by status: **All / Active / Completed**
- Persist tasks across reloads using `localStorage`
- Clean component structure and state management with React hooks

## ⚙️ Technologies Used

- **React** (functional components + hooks)
- **SCSS / CSS Modules / Tailwind** (depending on your setup)
- **ESLint + Prettier** for code consistency
- **gh-pages** for GitHub Pages deployment
- _(Optional)_ **TypeScript** for type safety
